# 老吴 (CatFight Mod)

猫咪打架模组 - Minecraft Fabric 1.20.1

## 功能
- 🐱 猫猫靠近自动对骂互殴
- 🏑 训猫棒左键打猫制止吵架（3分钟停战+静音）
- 🐟 小鱼干（鳕鱼+8金粒合成）喂猫→随机奖励
- 🌟 超级小鱼干（小鱼干+8金锭合成）喂猫→永久停战+金苹果
- 🎵 9种吵架音效随机播放
- 🔄 玩家周围40格动态扫描

## 合成配方
| 物品 | 配方 |
|------|------|
| 训猫棒 | 白羊毛 在上 + 2木棍 在下 |
| 小鱼干 | 8金粒环绕 + 生鳕鱼中心 |
| 超级小鱼干 | 8金锭环绕 + 小鱼干中心 |
